# Código de conducta

[English](CODE_OF_CONDUCT.md) | **Español**

Queremos una comunidad donde se pueda preguntar, equivocarse y aportar sin sentirse mal por ello. Este código aplica a issues, PRs, discusiones y cualquier espacio del proyecto.

## Qué esperamos

- Tratar a las personas con respeto, también cuando se discrepa.
- Criticar el código y las ideas, no a quien las escribió.
- Asumir buena fe y dar contexto antes de juzgar.
- Aceptar con elegancia una revisión, y darla con amabilidad.
- Escribir en español o en inglés; si alguien no domina el idioma, tener paciencia.

## Qué no se tolera

- Insultos, acoso, amenazas o descalificaciones personales.
- Comentarios discriminatorios por origen, género, orientación, discapacidad, edad, religión o cualquier otra condición.
- Atención sexual no deseada, *doxxing* o publicar datos privados de otras personas.
- Insistir tras un «no», o alterar a propósito una conversación (*trolling*, spam).

## Qué pasa si se incumple

Los mantenedores pueden editar o borrar comentarios, cerrar hilos, advertir, vetar temporalmente o expulsar de forma permanente, según la gravedad. Intentaremos ser proporcionados y explicar la decisión.

## Cómo avisar

Si ves o sufres una conducta que incumple esto, avisa por correo a <kevinccharpentier@gmail.com> (un canal privado hacia el mantenedor). Se tratará con discreción y no se tomarán represalias contra quien avise de buena fe.
